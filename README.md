# Jogo Sudoku

Aplicação Web completa para jogar Sudoku, dividida em arquitetura **Backend** e **Frontend**.

## 🚀 Arquitetura e Tecnologias

* **Frontend**: Interface de utilizador para interação com o tabuleiro do jogo.
* **Backend**: Serviços e API para validação de jogadas, geração de tabuleiros ou lógica do jogo.

## 📁 Estrutura do Projeto

* `Frontend/` - Código-fonte da interface web do utilizador.
* `backend/` - Regras de negócio, lógica do jogo e serviços da API.
